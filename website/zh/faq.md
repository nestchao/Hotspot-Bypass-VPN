# 常见问题

## 通用问题

### 这和普通的移动热点有什么区别？

普通移动热点使用 Android 内置的 tethering API，运营商可以检测到并进行限速/封锁。本应用使用 **Wi-Fi Direct**（点对点协议）在设备间创建直接连接，运营商看到的是普通手机间通信 —— 而非热点共享。

### 需要 Root 权限吗？

不需要。应用仅使用标准 Android API —— **VpnService** 和 **Wi-Fi Direct (WifiP2pManager)**。宿主手机和客户端手机都无需 Root。

### 任何 Android 手机都能用吗？

任何运行 **Android 7.0 (API 24)** 或更高版本、支持 **Wi-Fi Direct** 的手机都可以。大部分现代 Android 手机都支持 Wi-Fi Direct。

### 所有运营商都能用吗？

应用旨在绕过运营商热点检测，但我们无法保证适用于所有国家和地区的运营商。效果可能因运营商的检测方法而异。

### 这合法吗？

在大多数国家，使用 VPN 和 Wi-Fi Direct 分享网络连接是合法的。但运营商服务条款中的热点共享限制可能禁止此行为。使用前请查看运营商的条款。

## 设置与使用

### 为什么需要位置权限？

Android 要求 Wi-Fi Direct 发现和连接需要位置权限。应用**不会**使用你的实际 GPS 位置 —— 只是因为 Android API 要求才需要此权限。

### 什么是"私有 DNS"？为什么要关闭它？

私有 DNS（DNS over TLS）可能干扰 SOCKS5 代理。如果你设置了自定义私有 DNS 提供商（如 `dns.google`），应用会显示警告。请在手机网络设置中将其设为**关闭**或**自动**。

### 可以同时使用 Host 和 Client 模式吗？

不可以。应用会阻止两种模式同时运行以避免冲突。如果尝试在一个模式激活时切换，会看到警告提示。

### 为什么关闭应用后服务就停止了？

应用使用**前台服务**保持运行，但部分手机（尤其是小米、华为、一加）的激进电池管理可能会杀死前台服务。请确保：
- 授予**忽略电池优化**权限
- 将应用添加到手机的**受保护应用**或**自启动**列表
- 在最近任务列表中锁定应用

### 设备之间可以隔多远？

Wi-Fi Direct 通常在视距 **30-50 米**范围内工作。墙壁和障碍物会缩短有效距离。

## 性能

### 预期网速是多少？

速度取决于：
- 手机蜂窝连接速度
- Wi-Fi Direct 带宽（通常实际 30-50 Mbps）
- 设备间距离和障碍物
- 频段选择（5GHz 更快，2.4GHz 覆盖更好）

实际体验：多数场景下 **10-40 Mbps**。

### 适合游戏吗？

是的。应用专门针对游戏场景设计：
- **5GHz 频段**选项提供更低延迟
- SOCKS5 代理的 **UDP 支持**处理实时游戏流量
- **Windows TUN 网卡**提供完整游戏兼容性
- **ICS 桥接**支持游戏主机（PS5、Xbox、Switch）

典型延迟：在手机蜂窝延迟基础上增加 **30-60ms**。

### 流媒体能用吗（Netflix、YouTube 等）？

可以。SOCKS5 代理同时处理 TCP（流媒体）和 UDP（游戏/语音）流量。流媒体服务正常工作。

## Windows 客户端

### Windows 客户端为什么需要管理员权限？

应用需要管理员权限来创建和配置 TUN 虚拟网卡，以及修改系统路由表。这对 Windows 上的 VPN 软件来说是正常的。

### Windows 客户端能在台式机上用吗？

可以，只要台式机有 Wi-Fi（用于连接手机的 Wi-Fi Direct 网络）。没有 Wi-Fi 的台式机可以使用 USB Wi-Fi 网卡。

### Windows 客户端支持 Mac 吗？

不支持，桌面客户端仅限 Windows。但 Mac 可以通过 **ICS 桥接方式**连接 —— 先在 Windows 笔记本上运行 VPN，再通过热点分享给 Mac。

## 游戏主机与电视

### 可以直接将 PS5 连接到手机吗？

不能直接连接。PS5 无法运行 Android 应用，也原生不支持 SOCKS5 代理。需要使用 **Windows 笔记本作为桥接**（参见[非 App 设备指南](/zh/guide/non-app-devices)）。

### 桥接模式会增加延迟吗？

会的，但通常仅增加 **5-15ms**。对大多数游戏来说完全可以接受。

### 笔记本需要单独的 Wi-Fi 网卡吗？

部分笔记本可以在同一块 Wi-Fi 网卡上同时运行 VPN 和移动热点，但不是所有型号都支持。如果遇到问题，使用一块 **USB Wi-Fi 网卡**（约 10-15 美元）专门用于热点即可解决。
