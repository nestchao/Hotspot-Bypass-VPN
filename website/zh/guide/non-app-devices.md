# 非 App 设备使用指南

## 概述

无法安装 Android App 的设备（游戏主机、Mac、智能电视）仍然可以通过 **Windows 网络连接共享 (ICS)** 使用绕过后的网络连接。

搭建需要：
1. 一台运行 **Host 模式**的手机（热点源）
2. 一台运行 **Windows 客户端 VPN 模式**的笔记本
3. 目标设备连接到笔记本的移动热点

---

## 连接示意

```
[手机 (Host 模式)]
       |
   Wi-Fi Direct
       |
[Windows 笔记本 (VPN + 移动热点)]
       |
   Wi-Fi 热点
       |
[PS5 / Xbox / Switch / Mac / 电视]
```

---

## 前置条件

- 已启动 **Host 模式**的手机
- 一台 **Windows 笔记本**（10 或 11，64 位，带 Wi-Fi）
- 需要联网的**目标设备**

---

## 分步设置

### 第一步：手机设置

1. 打开手机应用。
2. 切换到 **HOST** 标签。
3. 点击**启动 Host**。
4. 记录连接信息（SSID、密码、代理 IP、端口）。

### 第二步：笔记本设置

1. 将笔记本连接到手机的 Wi-Fi Direct：**DIRECT-HotspotBypass**（密码：`87654321`）。
2. 启动 **Windows 客户端**并开启 VPN（参见 [Windows 使用指南](/zh/guide/windows)）。
3. 连接成功后，进入**设置 → 网络和互联网 → 移动热点**。
4. 开启**移动热点**。

### 第三步：配置 ICS

1. 打开**控制面板 → 网络和共享中心 → 更改适配器设置**。
2. 右键点击 **LaptopProxyVPN** TUN 网卡 → **属性**。
3. 进入**共享**标签。
4. 勾选**允许其他网络用户通过此计算机的 Internet 连接来连接**。
5. 在下拉菜单中选择你的移动热点适配器（通常名称为"本地连接* ##"或类似）。
6. 点击**确定**。

### 第四步：连接设备

1. 在游戏主机 / Mac / 电视上打开 Wi-Fi 设置。
2. 找到并连接到笔记本的移动热点网络。
3. 设备现在应该可以通过绕过后的网络上网了。

## 各设备说明

### PlayStation 5 / PlayStation 4

- 进入**设置 → 网络 → 设定 → 设定互联网连接**
- 选择**使用 Wi-Fi** → 选中笔记本的热点
- 无需配置代理 — ICS 会自动处理
- 在**设置 → 网络 → 连接状态**中测试连接

### Xbox Series X|S / Xbox One

- 进入**设置 → 一般 → 网络设置 → 设置无线网络**
- 选择笔记本的热点
- 进入**测试网络连接**验证

### Nintendo Switch

- 进入**系统设置 → 互联网 → 互联网设置**
- 选择笔记本的热点
- 测试连接

### MacBook

- 通过 Wi-Fi 连接到笔记本的热点
- 无需额外配置
- 适合游戏、浏览和流媒体

### 智能电视

- 打开**网络设置** → **Wi-Fi**
- 选择笔记本的热点
- 适用于流媒体应用（Netflix、YouTube 等）和网页浏览

## 性能提示

- **5GHz 频段** — 将手机设置为 5GHz Wi-Fi Direct 频段以获得更低延迟
- **距离** — 手机和笔记本保持在 10 米以内以获得最佳信号
- **有线桥接** — 如需最低延迟，可用网线将笔记本连接到主机而非 Wi-Fi 热点
- **关闭其他应用** — 减少手机上的带宽占用，提升游戏性能

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 设备可连接但无网络 | 检查 ICS 配置。重启移动热点。 |
| 高延迟 / 卡顿 | 将手机切换到 5GHz。缩短设备间距离。 |
| 热点未显示 | 确认笔记本支持 Windows 移动热点功能。 |
| 开启热点后 VPN 断开 | 部分 Wi-Fi 网卡无法同时处理两者。可尝试 USB Wi-Fi 网卡用作热点。 |
| 主机找不到热点 | 在 Windows 设置中将热点设为 2.4GHz 频段。 |
